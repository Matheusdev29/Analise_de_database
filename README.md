# Analise_de_database
Nesse Repositório coloco toda a documentação e cronograma do projeto de análise de dados da Liga de Data Science

---

## Contexto
Apartir de uma database de vendas da Samsung, praticar análise de dados e olhar analítico para extrair inferências
## principais Focos
1. **Descobrir o perfil de cliente da Samsung**
     > qual região ele mora?, qual é o segmento do cliente?
2. **Descobrir o Impacto do 5G nas vendas da Samsung**
     > Quais produtos foram impactados pelo 5g e se vale a pena investir em uma campanha de marketing sobre 5G
3. **Identificar os produtos que mais trazem receita**
     >Qual é a categoria desses produtos
     >Qual é a fatia de receita gerada por esses produtos
5. ** Fazer uma Previsão em relação as vendas futuras utilizando Random Forest**
